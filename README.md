## 🌐 העלאה לאינטרנט (GitHub Pages)

כדי להעלות את המשחק לאתר חינמי:

1. צור ריפוזיטורי חדש ב-GitHub
2. העלה את הקבצים:
   - index.html
3. כנס ל:
   - Settings → Pages
4. בחר:
   - Branch: main
   - Folder: /root
5. לחץ Save
6. תקבל לינק לאתר המשחק
